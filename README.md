# SaveMoney

Финансовая образовательная платформа: личный кабинет ученика, уроки по порядку (видео → домашнее задание → тест), отслеживание прогресса, финансовые инструменты и админка. Интерфейс на английском и русском, оплата курсов через Stripe (USD).

## Что умеет

**Ученик**
- Регистрация и вход, личный кабинет с общим прогрессом, средним баллом, последними попытками и балансом за месяц.
- Уроки открываются строго по порядку. В каждом уроке: видео YouTube → домашнее задание (проверяется автоматически) → тест. Следующий урок открывается только после зачёта домашки и теста предыдущего урока.
- Ответы проверяются на сервере, правильные ответы в браузер не попадают. Проходной балл задаётся для каждого урока (по умолчанию 70%). Попытки не ограничены и все сохраняются.
- Финансовые инструменты: учёт доходов и расходов по месяцам с категориями и долей сбережений, калькулятор накоплений (сложный процент с пополнениями), кредитный калькулятор (аннуитетный и дифференцированный платёж, график).
- Переключатель языка EN / RU.

**Администратор** (`/admin`)
- Курсы: название и описание на двух языках, цена в USD, публикация.
- Уроки: текст на двух языках, ссылка на YouTube, бесплатный пробный урок, проходной балл.
- Вопросы для домашки и теста: выбор варианта или числовой ответ с допустимой погрешностью.
- Ученики: прогресс по каждому уроку (видео, баллы, число попыток), выдать или забрать доступ к курсу вручную.

**Оплата**
- Stripe Checkout, после оплаты доступ открывается через webhook (и дополнительно при возврате на сайт).
- Если ключи Stripe не заданы, в режиме разработки вместо оплаты показывается кнопка тестовой разблокировки. В production без ключей покупка не работает.

## Видео YouTube

Видео с доступом **«Private»** нельзя встроить на сайт: YouTube показывает их только аккаунтам, которым автор открыл доступ. Поэтому загружайте уроки с доступом **«Unlisted» (по ссылке)**: в поиске YouTube их нет, а на сайте они открываются только у тех, кто прошёл до этого урока. Видео встраивается через `youtube-nocookie.com`.

Если позже понадобится полная защита от пересылки ссылок, видео можно перенести на Vimeo (с ограничением встраивания по домену) или Mux.

## Стек

Next.js 15 (App Router, Server Actions) · TypeScript · PostgreSQL + Prisma · Tailwind CSS · Stripe · собственная авторизация (bcrypt + подписанная cookie через `jose`).

## Запуск локально

Нужны Node.js 20+ и PostgreSQL.

```bash
cp .env.example .env          # заполните DATABASE_URL и AUTH_SECRET (openssl rand -hex 32)
npm install
npx prisma migrate deploy     # создаёт таблицы
npm run db:seed               # админ + демо-курс «Основы личных финансов» (4 урока)
npm run dev                   # http://localhost:3000
```

Админ по умолчанию: `admin@savemoney.local` / `admin12345` (задаётся через `ADMIN_EMAIL` и `ADMIN_PASSWORD` до запуска seed). Смените пароль перед запуском в production.

## Подключение Stripe

1. В [Stripe Dashboard](https://dashboard.stripe.com/apikeys) возьмите Secret key и пропишите `STRIPE_SECRET_KEY`.
2. Создайте webhook на `https://ваш-домен/api/stripe/webhook` с событиями `checkout.session.completed` и `checkout.session.async_payment_succeeded`, его секрет пропишите в `STRIPE_WEBHOOK_SECRET`.
3. Укажите `APP_URL` (адрес сайта) для возврата после оплаты.

Локально webhook можно проверить через `stripe listen --forward-to localhost:3000/api/stripe/webhook`.

## Деплой

Подходит Vercel + управляемый PostgreSQL (Neon, Supabase, Railway). Переменные окружения из `.env.example`, команда сборки `npm run build`, перед первым запуском `npx prisma migrate deploy` и `npm run db:seed`.

## Структура

```
prisma/schema.prisma        модели: User, Course, Lesson, Question, Enrollment, LessonProgress, Attempt, Transaction
prisma/seed.ts              админ и демо-курс
src/lib/learning.ts         правила открытия уроков и расчёт прогресса
src/lib/finance.ts          формулы калькуляторов
src/app/actions/            серверные действия: вход, уроки и оценка, бюджет, админка
src/app/lessons/[id]        страница урока
src/app/dashboard           кабинет ученика
src/app/tools/              доходы и расходы, накопления, кредит
src/app/admin/              админка
src/i18n/                   переводы EN и RU
```
